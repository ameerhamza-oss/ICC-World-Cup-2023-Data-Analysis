# 🏏 ICC World Cup 2023 Data Analysis

## 📌 Project Overview
This project analyzes ICC Cricket World Cup 2023 data using Python.  
The goal is to explore team performance, player statistics, and match insights through data analysis and visualization.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset
Dataset: ICC World Cup 2023 cleaned data (`Icc2023_cleaned.csv`)

The dataset contains match-related information used for analyzing cricket performance and trends.

## 📊 Analysis Performed
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Player performance analysis
- Team performance analysis
- Data visualization using charts

## 📈 Key Insights
- Analyzed batting and bowling performances
- Explored team winning patterns
- Visualized important cricket statistics
